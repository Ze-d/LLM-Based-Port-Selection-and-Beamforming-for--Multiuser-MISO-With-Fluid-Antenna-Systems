# Imperfect CSI 下的 LLM + Beamforming + FAS 论文方向指导文档

## 1. 研究方向一句话定位

本研究拟探索 **Imperfect CSI 条件下，基于不确定性感知 LLM 的 Fluid Antenna System 联合端口选择与波束赋形方法**。

更具体地说：

> 本文针对多用户 MISO-FAS 系统中 CSI 估计误差导致端口选择和波束赋形性能退化的问题，提出一种 uncertainty-aware / risk-sensitive LLM-FAS 框架，使模型能够显式感知 CSI 不确定性，并输出鲁棒的端口选择和波束赋形决策。

---

## 2. 为什么这个方向值得做

Fluid Antenna System 的优势在于通过动态选择端口或天线位置，为无线系统提供额外空间自由度。相比固定天线阵列，FAS 可以在有限硬件规模下获得更灵活的信道重构能力。

但是 FAS 的性能高度依赖 CSI。如果 CSI 准确，系统可以选择信道条件最优的端口并设计波束赋形；但在实际系统中，CSI 往往存在估计误差、反馈延迟、导频污染、信道老化和硬件误差。因此，基于估计 CSI 得到的“最优端口”和“最优波束”在真实信道下可能并不鲁棒。

已有 LLM-FAS 工作已经证明，LLM/Transformer 结构可以用于高维端口选择与波束赋形联合优化。但这类工作主要关注理想 CSI 或估计 CSI 到端口/BF 的直接映射，没有把 CSI uncertainty 作为核心建模对象。

因此，本方向的关键不是简单地说：

> 把 imperfect CSI 加入 LLM-FAS。

而应该表述为：

> 构建一个显式感知 CSI 不确定性的鲁棒 LLM-FAS 框架，使模型在 CSI error 存在时仍然能够稳定选择端口并生成鲁棒波束赋形。

---

## 3. 与已有工作的关系和新颖性边界

### 3.1 已有工作 1：LLM + FAS + Port Selection + Beamforming

已有论文已经提出基于 LLM 的 FAS 端口选择与波束赋形方法。其核心是使用 LLM/LoRA 学习从 CSI 到端口选择和波束赋形的映射，并通过 Gumbel-Sinkhorn 等方式处理离散端口选择问题。

因此，本研究不能声称：

> 首次提出 LLM-FAS beamforming。

这部分已经有人做过。

---

### 3.2 已有工作 2：LLM + FAS + Port Prediction

已有 Port-LLM 类工作使用 LLM 预测 fluid antenna 的移动端口，主要面向 UE 移动场景。它的输入通常是历史信道表，输出是未来端口位置或端口选择。

这类工作和本研究相关，但侧重点不同：

* Port-LLM：侧重端口预测；
* 本研究：侧重 imperfect CSI 下的鲁棒端口选择与波束赋形联合优化。

---

### 3.3 已有工作 3：LLM + FAS + Channel Prediction

已有 FAS-LLM 类工作使用 LLM 做 FAS 信道预测，例如 OTFS-enabled satellite-FAS 场景中的未来信道预测。其目标是提升信道预测精度，并用于后续链路自适应。

这类工作说明 LLM 可以处理 FAS 中的时序信道建模问题，但它不是直接解决：

> imperfect CSI 下的 robust port selection + robust beamforming。

---

### 3.4 已有工作 4：Imperfect CSI + FAS/MA 鲁棒优化

已有不少传统优化方法研究 imperfect CSI 下的 FAS 或 movable antenna 设计，例如：

* worst-case robust optimization；
* stochastic robust optimization；
* S-procedure；
* SCA；
* AO；
* GA；
* gradient-based antenna position optimization。

这些方法说明 imperfect CSI 下的 FAS/MA 鲁棒设计本身已经有人研究。

因此，本研究不能声称：

> 首次研究 imperfect CSI 下的 FAS beamforming。

真正的差异在于：

> 本研究使用 LLM 进行不确定性感知的快速鲁棒决策，而不是依赖传统迭代优化。

---

### 3.5 当前较安全的新颖性表述

最安全的创新边界是：

> 已有 LLM-FAS 工作主要关注理想或估计 CSI 下的端口选择与 BF；已有 imperfect CSI-FAS 工作主要依赖传统优化或学习方法。本文研究 imperfect CSI 下 uncertainty-aware LLM-FAS 联合端口选择与波束赋形，通过 CSI uncertainty tokenization、risk-sensitive robust training 和 robust BF parameterization 提高真实信道下的 sum-rate、outage 和端口选择稳定性。

---

## 4. 推荐论文题目

不建议使用：

> LLM-Based Port Selection and Beamforming for FAS under Imperfect CSI

这个题目和已有 LLM-FAS 工作太接近，容易被认为只是已有工作的 noisy CSI extension。

更推荐：

### 题目 1

**Uncertainty-Aware LLM-Based Robust Port Selection and Beamforming for Multiuser MISO Fluid Antenna Systems**

### 题目 2

**Risk-Sensitive LLM-Driven Joint Port Selection and Beamforming for Fluid Antenna Systems with Imperfect CSI**

### 题目 3

**Two-Timescale Robust LLM-FAS: Uncertainty-Aware Port Selection and Beamforming under Imperfect CSI**

最推荐题目 3，因为它同时突出：

* two-timescale；
* robust；
* uncertainty-aware；
* LLM-FAS；
* imperfect CSI。

## 5. 系统模型

考虑一个多用户下行 MISO-FAS 系统：

* 基站配备二维 FAS；
* 共有 (N) 个候选端口；
* 由于 RF chain 数量有限，每次只激活 (n) 个端口；
* 系统服务 (K) 个单天线用户；
* 需要联合优化：

  * 端口选择矩阵 (S)；
  * 波束赋形矩阵 (W)。

真实 CSI 为：

[
H
]

估计 CSI 为：

[
\hat{H}
]

二者关系为：

[
\hat{H} = H + E
]

或者：

[
H = \hat{H} + \Delta H
]

其中 (E) 或 (\Delta H) 表示 CSI 估计误差。

用户 (k) 的接收信号可以表示为：

[
y_k = h_k^H(S) w_k s_k + \sum_{j\neq k} h_k^H(S) w_j s_j + n_k
]

对应 SINR 为：

[
\mathrm{SINR}_k(H,S,W)
======================

\frac{|h_k^H(S)w_k|^2}
{\sum_{j\neq k}|h_k^H(S)w_j|^2+\sigma^2}
]

系统真实 sum-rate 为：

[
R(H,S,W)
========

\sum_{k=1}^{K}
\log_2(1+\mathrm{SINR}_k(H,S,W))
]

重点是：训练和测试时，不能只在估计 CSI (\hat{H}) 上计算性能，而应该在真实 CSI (H) 上评估。

---

## 6. 核心问题定义

传统 LLM-FAS 学习的是：

[
\hat{H} \rightarrow (S,W)
]

但在 imperfect CSI 下，这样会有问题，因为 (\hat{H}) 可能包含误差。模型如果盲目相信 (\hat{H})，可能会选择估计上很强、但真实信道下不稳定的端口。

因此，本文希望学习的是：

[
(\hat{H}, U, G, P) \rightarrow (S,W)
]

其中：

* (\hat{H})：估计 CSI；
* (U)：CSI uncertainty 信息，例如误差方差、误差协方差、channel aging coefficient；
* (G)：FAS 端口几何信息；
* (P)：用户 pathloss、QoS 权重等长期信息；
* (S)：选择的端口；
* (W)：波束赋形矩阵或波束赋形参数。

优化目标不是估计 CSI 下的 rate，而是真实信道不确定性下的鲁棒性能：

[
\max_{S,W}
\mathcal{R}_{robust}(S,W|\hat{H})
]

可选目标包括：

### 目标 1：Expected Sum-Rate

[
\mathbb{E}_{H|\hat{H}}
[
R(H,S,W)
]
]

### 目标 2：Worst-Case Sum-Rate

[
\min_{\Delta H \in \mathcal{U}}
R(H,S,W)
]

### 目标 3：CVaR Sum-Rate

关注最差一部分信道扰动样本下的平均性能。

最推荐使用 CVaR，因为它比 average 更鲁棒，又比 worst-case 更容易训练。

---

## 7. 方法框架

推荐方法名称：

**RU-LLM-FAS**

即：

**Robust Uncertainty-Aware LLM for Fluid Antenna Systems**

整体流程：

```text
Estimated CSI \hat{H}
+ CSI uncertainty descriptor U
+ FAS port geometry G
+ user/pathloss information P
        ↓
CSI-Uncertainty Tokenizer
        ↓
LoRA-finetuned LLM Backbone
        ↓
Parallel Decision Heads
        ├── Port Selection Head
        ├── Robust BF Parameter Head
        └── Risk / Reliability Head
        ↓
RZF / WMMSE-inspired Physical Layer
        ↓
Risk-sensitive Robust Training Loss
```

---

## 8. 模块设计

### 8.1 CSI-Uncertainty Tokenizer

这是本方向最重要的创新之一。

传统做法只输入：

[
\Re(\hat{H}), \Im(\hat{H})
]

本文建议输入：

[
x_{k,n}
=======

[
\Re(\hat{h}*{k,n}),
\Im(\hat{h}*{k,n}),
\sigma^2_{e,k,n},
\rho_{k,n},
x_n,
y_n,
\beta_k
]
]

其中：

* (\Re(\hat{h}_{k,n}))：估计信道实部；
* (\Im(\hat{h}_{k,n}))：估计信道虚部；
* (\sigma^2_{e,k,n})：CSI 误差方差；
* (\rho_{k,n})：信道可靠性或时间相关系数；
* (x_n,y_n)：端口几何位置；
* (\beta_k)：用户 pathloss 或大尺度衰落。

这样模型可以学到：

* 哪些端口估计信道强但不可靠；
* 哪些端口估计信道略弱但稳定；
* 哪些端口之间空间相关性强，不适合同时激活；
* 哪些用户的 CSI 更容易出错，需要更保守的 BF。

---

### 8.2 LLM Backbone

建议第一版不要直接使用很大的 LLM。

可选模型：

* GPT-2 small；
* DistilGPT2；
* small Transformer decoder；
* TinyLLaMA 级别模型。

训练方式：

* 冻结大部分 backbone；
* 使用 LoRA 进行参数高效微调；
* 只训练输入 embedding、LoRA 层和任务 head。

这可以降低训练成本，也方便做 ablation。

---

### 8.3 Port Selection Head

端口选择是离散问题，不方便直接反向传播。

可以使用：

* Gumbel-TopK；
* Gumbel-Sinkhorn；
* straight-through estimator。

训练阶段使用 soft selection，推理阶段使用 hard selection。

端口选择 head 输出：

[
z_n = f^{port}*{\theta}(h*{\text{LLM}})
]

然后得到端口集合：

[
S = \mathrm{TopK}(z)
]

---

### 8.4 Robust BF Parameter Head

不建议第一版让 LLM 直接输出完整复数波束矩阵 (W)，因为这样训练不稳定，也不够物理。

更推荐让 LLM 输出：

[
S, \alpha, p_1,\dots,p_K
]

然后通过 RZF 层计算：

[
W =
\eta
\hat{H}_S^H
(\hat{H}_S\hat{H}_S^H+\alpha I)^{-1}
P^{1/2}
]

其中：

* (S)：端口选择结果；
* (\alpha)：RZF 正则化参数；
* (p_k)：用户功率分配；
* (\eta)：功率归一化因子。

这样做的优势是：

1. 保留物理结构；
2. 训练更稳定；
3. 方便满足功率约束；
4. (\alpha) 可以随 CSI error 自适应变化；
5. 当 CSI error 大时，模型可以自动选择更保守的 BF。

---

### 8.5 Risk / Reliability Head

可以增加一个辅助 head，预测当前决策的可靠性：

[
r = f^{risk}*{\theta}(h*{\text{LLM}})
]

该 head 可以预测：

* 当前端口选择是否稳定；
* 当前 BF 是否容易导致 outage；
* 当前 CSI error 下的 rate degradation 风险。

这个模块不是必须，但可以作为增强创新点。

---

## 9. 鲁棒训练目标

训练时，对每个估计 CSI (\hat{H})，采样多个可能真实信道：

[
H^{(m)} = \hat{H} + \Delta H^{(m)}, \quad m=1,\dots,M
]

然后在这些真实信道上计算 sum-rate。

### 9.1 Average Robust Loss

[
\mathcal{L}
===========

*

\frac{1}{M}
\sum_{m=1}^{M}
R(H^{(m)},S,W)
]

优点：简单稳定。
缺点：可能只优化平均性能，对 outage 不敏感。

---

### 9.2 Worst-Sample Loss

[
\mathcal{L}
===========

*

\min_m
R(H^{(m)},S,W)
]

优点：鲁棒性强。
缺点：训练可能不稳定。

---

### 9.3 CVaR Loss

选取最差的 (q%) 信道样本，最大化其平均 rate：

[
\mathcal{L}
===========

*

\frac{1}{|\mathcal{M}*{worst}|}
\sum*{m\in\mathcal{M}_{worst}}
R(H^{(m)},S,W)
]

最推荐使用 CVaR loss，因为它兼顾稳定性和鲁棒性。

---

## 10. Two-Timescale 设计

这是增强论文创新性的关键。

FAS 端口选择和波束赋形的更新频率不一定相同。

### 慢时间尺度：Port Selection

输入：

```text
statistical CSI
+ pathloss
+ port correlation
+ long-term CSI uncertainty
```

输出：

```text
active port set S
```

端口选择不应频繁随瞬时 CSI 噪声变化，而应根据长期稳定信道结构和端口可靠性进行选择。

---

### 快时间尺度：Beamforming

输入：

```text
instantaneous estimated CSI
+ instantaneous uncertainty level
+ selected port set S
```

输出：

```text
robust BF parameters \alpha, p
```

波束赋形可以根据瞬时估计 CSI 快速更新。

---

### Two-Timescale 的核心逻辑

端口选择负责长期空间结构重构，波束赋形负责短期多用户干扰抑制。

在 imperfect CSI 下，端口选择如果过度追随 noisy instantaneous CSI，可能导致端口频繁切换和性能不稳定。因此，two-timescale 设计更符合 FAS 实际部署逻辑。

---

## 11. 实验设计

### 11.1 基本设置

推荐第一版实验设置：

* 系统：downlink multiuser MISO-FAS；
* 用户数：(K=4)；
* 候选端口数：(N=16) 或 (N=32)；
* 激活端口数：(n=K)；
* 信道模型：Rayleigh / Rician；
* 端口相关性：Jakes spatial correlation；
* CSI error：

[
\eta =
\frac{\mathbb{E}|\Delta H|_F^2}
{\mathbb{E}|H|_F^2}
]

可设置为：

[
\eta \in {0,0.01,0.03,0.05,0.1,0.2}
]

### 11.2 Baselines

必须设置强 baseline。

#### 传统优化 baseline

* Greedy strongest port + RZF；
* GA-based port selection + RZF；
* AO + WMMSE；
* sample-average robust WMMSE；
* worst-case robust RZF。

#### 学习 baseline

* MLP；
* CNN；
* Transformer；
* 原始 LLM-FAS；
* LLM-FAS + noisy training；
* LLM-FAS without uncertainty token；
* LLM-FAS without CVaR loss；
* Proposed RU-LLM-FAS。

---

### 11.3 评价指标

不能只看 average sum-rate。

建议指标：

1. True sum-rate：

[
R(H,S,W)
]

注意：在真实 CSI (H) 上计算，不是在 (\hat{H}) 上计算。

2. Outage probability：

[
P(R<R_{th})
]

3. 5%-outage rate。

4. Minimum user rate：

[
\min_k R_k
]

5. SINR violation probability：

[
P(\mathrm{SINR}_k<\gamma_k)
]

6. Port selection stability：

[
\mathrm{Stability}
==================

1-
\frac{d_H(S_1,S_2)}{n}
]

7. Inference latency。

8. Robustness degradation：

[
\Delta R
========

## R_{\text{perfect CSI}}

R_{\text{imperfect CSI}}
]

## 14. 最容易被质疑的点与应对

### 质疑 1：为什么用 LLM，不用普通 Transformer？

应对：

需要做 MLP / CNN / Transformer / GPT2 / LoRA-LLM 对比。强调 LLM 的价值不是语言能力，而是：

* 高维 token 序列建模；
* 多任务输出；
* 对用户、端口、误差水平的泛化；
* LoRA 低成本适配；
* 可扩展到 channel prediction、port prediction、BF decision 多任务。

---

### 质疑 2：这是不是只是 noisy training？

应对：

必须突出三个机制：

1. uncertainty-aware token；
2. risk-sensitive CVaR loss；
3. robust BF parameterization。

如果只是给 CSI 加噪声训练，创新性不够。

---

### 质疑 3：端口选择不可导怎么办？

应对：

使用 Gumbel-TopK / Gumbel-Sinkhorn / straight-through estimator。

训练时 soft selection，测试时 hard selection。

---

### 质疑 4：为什么不直接输出 BF 矩阵？

应对：

直接输出自由 (W) 容易不满足物理约束，也容易训练不稳定。输出 RZF/WMMSE 参数更稳，更容易满足功率约束，也更容易解释 CSI error 下的正则化行为。

---

### 质疑 5：已有 LLM-FAS 和 LLM 自动算法设计工作是否会撞题？

应对：

已有工作主要做：

* LLM-FAS 端口选择与 BF；
* LLM 预测 FAS 端口；
* LLM 做 FAS 信道预测；
* LLM 自动设计启发式优化算法。

本文重点不是“LLM 能不能用于 FAS”，而是：

> imperfect CSI 下，LLM 如何显式利用 CSI uncertainty 做鲁棒端口选择与波束赋形。

因此题目和贡献必须围绕：

* uncertainty-aware；
* robust；
* risk-sensitive；
* imperfect CSI；
* two-timescale；
* true-rate under channel perturbations。

---

## 15. 最终建议的论文主线

这篇论文最稳的主线是：

> FAS 提供端口选择自由度，但其性能高度依赖 CSI。已有 LLM-FAS 方法可以快速学习高维 CSI 到端口选择和 BF 的映射，但在 imperfect CSI 下，模型若盲目相信估计 CSI，可能选择不可靠端口并产生严重残余干扰。为此，本文提出 uncertainty-aware robust LLM-FAS 框架，将估计 CSI、CSI error statistics、端口几何和用户长期信息联合 token 化，并通过 CVaR-based risk-sensitive training 在多个真实 CSI 扰动样本上优化 true sum-rate。进一步地，本文采用物理启发的 RZF 参数化输出和 two-timescale port-BF decision，从而在 CSI error、channel aging 和反馈不确定性下获得更高 true sum-rate、更低 outage 和更稳定端口选择。

---

## 16. 当前方向判断

本方向可以继续推进，但必须避免低创新写法。

不推荐的写法：

> 我们将 LLM-FAS 扩展到 imperfect CSI 场景。

推荐写法：

> 我们提出一种不确定性感知的鲁棒 LLM-FAS 框架，用于 imperfect CSI 下的联合端口选择与波束赋形。

最终核心关键词应锁定为：

```text
Fluid Antenna System
Imperfect CSI
Uncertainty-Aware Tokenization
Robust Beamforming
Risk-Sensitive Training
CVaR Sum-Rate
Two-Timescale Decision
LoRA-Finetuned LLM
Port Selection
RZF Parameterization
```

## 17. 下一步执行路线

### Step 1：复现或搭建基础 LLM-FAS

先实现 perfect CSI 下：

```text
CSI → port selection + RZF/BF
```

确保可以跑通：

* sum-rate；
* port selection；
* baseline；
* inference time。

---

### Step 2：加入 imperfect CSI 数据生成

生成：

[
\hat{H}=H+E
]

设置不同 CSI error level：

[
\eta \in {0,0.01,0.03,0.05,0.1,0.2}
]

验证原始模型是否退化。

---

### Step 3：加入 uncertainty token

输入从：

```text
Re(H_hat), Im(H_hat)
```

扩展为：

```text
Re(H_hat), Im(H_hat), sigma_e^2, port geometry
```

做 ablation。

---

### Step 4：加入 robust loss

从 average true-rate loss 开始，再升级到 CVaR loss。

---

### Step 5：加入 RZF parameterization

让模型输出：

```text
port set S
regularization alpha
power allocation p
```

而不是直接输出完整 BF 矩阵。

---

### Step 6：加入 two-timescale 版本

慢尺度选择端口，快尺度更新 BF。

这是 v1/v2 版本，不建议一开始就做。

---

## 18. 最终结论

当前方向不是完全空白，因为已有 LLM-FAS、Port-LLM、FAS-LLM 和 imperfect CSI-FAS 鲁棒优化工作。

但是，如果将研究问题明确限定为：

> Imperfect CSI 下，基于 uncertainty-aware LLM 的 FAS 联合端口选择与鲁棒波束赋形。

并加入：

1. CSI uncertainty tokenization；
2. CVaR / risk-sensitive robust training；
3. RZF/WMMSE-inspired robust BF parameterization；
4. two-timescale port-BF decision；
5. true CSI 下的鲁棒性能评估；

那么这个方向仍然具备较清晰的新颖性边界和论文推进价值。
